Route Optimizer

How to use

Getting started

  • To start, you'll need a free Google Maps API key. Setup is explained in Settings.

Setting up your route

  • Enter a start location and your stops, choose how the route should end, then tap Optimize.
  • Tap the 🎯 icon by the start location to use your current location.

Choose your destination

  • No End: the route stops at the last optimized stop. Best when you want the most optimal route, regardless of where you end up.
  • Round Trip: the route loops back to your start location. Best when you begin and end at the same place.
  • End Address: the route finishes at a specific address you enter. Best when you know where you want to end.

Tools & features

  • Reorder: press and hold the ≡ icon, then drag it up or down.
  • Lock: tap the 🔓 icon to lock a stop (🔒) and prevent it from moving after optimization. Need to hit stop 5 first even though it's out of the way? Drag it to position 1 and pin it — every other stop is then optimized around it.
  • Delete: tap the ✕ to remove an address. Tap the ✕ next to Optimize to clear all address entries.

Route breakdown

  • After optimizing, the summary shows your total distance and drive time, plus the number of stops. Tap it to open the full breakdown, which lists every stop in order with the distance and time between each one.
  • In the breakdown, tap any address to see how much time and distance to reach that stop, and how much still remains.
  • Tap the 🕐 clock on a selected stop and enter a target arrival time — it tells you when to leave, factoring in drive time plus a 7 min buffer per stop along the way.

Map

  • Use two fingers to move around the map and pinch to zoom.
  • Tap any numbered marker to see that stop's address.

Saved routes & history

  • Save a route: after optimizing, tap 💾 Save Route to store it. You can give it a name — saving with an existing name overwrites that route. Then tap the 💾 icon at the top anytime to reload a saved route.
  • History: tap 🕘 to see recent routes. Every route you optimize or accidentally clear is saved here automatically. Entries expire after 3 days.

Turn on Advanced UI in Settings for more features.

Settings

Set up your own free API key:

  • Go to the Google Cloud Console and sign in.
  • Create a project (or pick an existing one) from the project menu at the top.
  • Open APIs & Services → Library and enable these four APIs:
    • Maps JavaScript API
    • Directions API
    • Places API
    • Geocoding API
  • Go to APIs & Services → Credentials → Create credentials → API key.
  • Copy the key it gives you and paste it into the field above.
  • Recommended: click the key to add restrictions — limit it to the four APIs above, and set an HTTP referrer restriction to your app's URL to keep it private.

Google's Maps Platform includes a monthly free usage credit, so normal personal use is typically free. You'll need to add a billing account to activate the key.
