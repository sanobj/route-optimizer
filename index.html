Route Optimizer

How to use

Enter a start location and your stops, choose how the route should end, then tap Optimize.

Choose your destination

  • No End: the route stops at the last optimized stop. Best when you don't need to return anywhere.
  • Round Trip: the route loops back to your start location. Best when you begin and end at the same place.
  • End Address: the route finishes at a specific address you enter. Best when you know where you want to end.

Tools & features

  • Reorder: press and hold the ≡ handle on a stop, then drag it up or down.
  • Pin / lock: tap the 🔓 icon to lock a stop and prevent it from moving after optimization. For example, need to hit stop 5 first even though it's out of the way? Drag it to position 1 and pin it — every other stop is then optimized around it.
  • Delete one stop: tap the ✕ on that stop's row.
  • Clear everything: tap the large ✕ next to Optimize to delete the whole list.

Saved routes & history

  • Save a route: tap 💾 to store the current route so you can reload it anytime. You can give it a name — saving with an existing name overwrites that route.
  • History: tap 🕘 to see recent routes. Every route you optimize or accidentally clear is saved here automatically, and entries expire after 3 days.

Settings

Set up your own free API key:

  • Go to the Google Cloud Console and sign in.
  • Create a project (or pick an existing one) from the project menu at the top.
  • Open APIs & Services → Library and enable these four APIs:
    • Maps JavaScript API
    • Directions API
    • Places API
    • Geocoding API
  • Go to APIs & Services → Credentials → Create credentials → API key.
  • Copy the key it gives you and paste it into the field above.
  • Recommended: click the key to add restrictions — limit it to the four APIs above, and set an HTTP referrer restriction to your app's URL to keep it private.

Google's Maps Platform includes a monthly free usage credit, so normal personal use is typically free. You'll need to add a billing account to activate the key.

Advanced UI adds:

• Bus/Res priority (swipe right on a stop to select)

◦ Business — always optimized first

◦ Residence — optimized after businesses

◦ Default — no priority

• Rush (tap the numbered circle to toggle)

◦ Gold circle = marked as rush

• Swipe left on any address to delete it
